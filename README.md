# Maleghast New Recruit Extension

Maleghast extension for the New Recruit app/website. To use, just go to New Recruit, in the "Games" tab go to "Add more games", then "Add from Github", and paste the URL from this repo in the URL field.

## Features

When creating a list, always leave Cost Limits at -1, Dark Power features are managed through the Configuration features in each list.

In the configuration section, you can set the Malice level of the list and you will get an according amount of Dark Powers. Then, you can spend those in the Dark Power Upgrades field (press the + symbol next to Configuration in the app for it to show up) or in your Dark Masses' Necromancer profile.

You can also enable Heresy mode through the Configuration, which will let you enable the "Heretic Houses" menu, where you can enable which houses' units will show up in your roster for easier sorting.

That should be most of it. All base houses and their rules are available except for Volvadani, who have neither rules nor nigromancer upgrades.
